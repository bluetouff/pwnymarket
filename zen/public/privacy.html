Les seules petites lignes sérieuses

Votre IP n’a pas sa carte de membre.

Aucun compte, cookie de suivi, stockage local dans le navigateur, pixel publicitaire ou service de statistiques tiers n’est utilisé par PwnyMarket.

Une voix par IP et par marché

L’adresse IP est nécessaire en mémoire pour recevoir votre connexion et limiter les doublons. Avant d’enregistrer le vote, le serveur la transforme en empreinte HMAC avec un secret serveur et l’identifiant du marché. Le journal des votes conserve seulement cette empreinte, le marché, le choix et sa date.

Le journal ne contient pas votre adresse brute. Une même IP produit des empreintes différentes selon le marché : elles ne constituent pas un identifiant transversal. Ces empreintes sont pseudonymisées, pas une promesse d’anonymat absolu. Elles restent conservées tant que le marché est ouvert pour empêcher les votes multiples.

GoAccess, sans vous compter deux fois comme une personne

Les statistiques techniques privées comptent les requêtes, les codes HTTP et les octets transférés. Les journaux dédiés enregistrent l’heure et une catégorie de route issue d’une liste fermée. Ils n’enregistrent ni IP, ni paramètres d’URL, ni navigateur, ni référent, ni contenu de vote. Les chemins inconnus sont regroupés, pas recopiés.

Le rapport GoAccess est réservé à l’administration du site, protégé par mot de passe et actualisé toutes les quinze minutes. Il n’affiche pas de visiteurs uniques, de pays ou de profils : les requêtes peuvent aussi provenir de robots. Les journaux sont limités à quatorze jours et à une taille bornée. Les erreurs techniques du serveur peuvent faire l’objet de journaux distincts et minimaux.

Les limites, sans poudre aux yeux

La déduplication par IP n’identifie pas une personne : foyer, entreprise ou réseau mobile peuvent partager une adresse. Un changement d’IP peut permettre un autre vote. Le serveur ne tente pas de vous reconnaître avec une empreinte du navigateur.

Le secret reste hors du dépôt public. Le code et la configuration sont consultables sur GitHub. Pour une question sur le fonctionnement, ouvrez-y une issue sans publier d’IP, de secret ou d’information personnelle.
